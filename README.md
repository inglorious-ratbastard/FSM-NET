##### A modern travel and cultural heritage web application focused on the islands of Micronesia, built with ASP.NET Core Razor Pages in a Single Page Application (SPA) style architecture.

#### Live Demo

##### Visit the application here:  
https://fsm-net.up.railway.app/

---

#### About

##### Micronesia Travel App is designed to showcase the beauty, culture, and heritage of the Pacific Islands while providing users with an interactive travel planning experience.

##### The application combines a lightweight SPA-like experience with ASP.NET Core Razor Pages to create a fast, responsive, and user-friendly travel platform.

#### Key Goals

##### - Promote Micronesian culture and heritage
##### - Provide travel information and destination discovery
##### - Support cultural preservation through digital experiences
##### - Deliver a modern responsive UI for travelers and explorers

---

#### Features

##### - SPA-style navigation using ASP.NET Razor Pages
##### - Travel destination browsing
##### - Pacific Islands cultural exploration
##### - Responsive hybrid-style web experience
##### - UIkit-powered modern interface
##### - Travel guide and planning functionality
##### - Cultural heritage presentation

##### Folder Structure 
###### FSM-NET 
###### - `Pages/` — Razor Pages views and routes  
###### - `wwwroot/` — Static frontend assets  
###### - `bin/Debug/net9.0/` — Build output files  
###### - `obj/` — Temporary build and compilation files  
###### - `.idx/` — Firebase Studio workspace configuration  
###### - `.vscode/` — VS Code workspace settings  
###### - `.dockerignore` — Docker ignore configuration  
###### - `.editorconfig` — Code style and formatting rules  
###### - `Dockerfile` — Docker container configuration  
###### - `GEMINI.md` — Firebase Studio/Gemini project notes  
###### - `Program.cs` — ASP.NET Core application entry point  
###### - `appsettings.json` — Main application configuration  
###### - `appsettings.Development.json` — Development environment settings  
###### - `myapp.csproj` — ASP.NET Core project configuration  
###### - `README.md` — Project documentation
